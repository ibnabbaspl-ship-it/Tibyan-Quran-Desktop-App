# Tibyan-Quran-Desktop-App
«مقرأة التبيان لعلوم القرآن» منظومة مكتبية محمولة ووقفٌ لله تعالى، لخدمة شيوخ الإقراء وحلقات التحفيظ؛ تُتيح إدارة المقرئين والطلاب، وتوثيق التسميع اليومي بالرواية أو القراءة أو الجمع، وضبط أحكام التجويد بعارض مصحف فوري، مع باحث قرآني وتفاسير وإعراب شامل، وتوثيق سلاسل الأسانيد وإصدار الإجازات بالسند المتصل إلى رسول الله ﷺ.
